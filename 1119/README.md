# 사칙연산 및 레지스터 출력 프로그램 (8086 Assembly)

> 2026년 11월 19일 수업 실습

두 개의 숫자를 입력받아 **사칙연산(+, -, ×, ÷)** 을 수행하고, 연산이 모두 끝난 직후의 **AX, BX, CX, DX 레지스터 내용**을 화면에 출력하는 DOS용 어셈블리 프로그램입니다.

---

## 1. 개요

| 항목 | 내용 |
|------|------|
| 파일 | `CALC_REG.ASM` |
| 언어 | x86 (8086) Assembly, MASM/TASM 문법 |
| 실행 환경 | DOS, DOSBox, EMU8086 |
| 입력 | 0 ~ 65535 범위의 10진수 2개 |
| 출력 | 사칙연산 결과, 연산 직후 AX·BX·CX·DX 값 (16진수 + 10진수) |

---

## 2. 빌드 및 실행

**MASM**
```
MASM CALC_REG.ASM;
LINK CALC_REG.OBJ;
CALC_REG
```

**TASM**
```
TASM CALC_REG.ASM
TLINK CALC_REG.OBJ
CALC_REG
```

> 파일 이름은 바꿔도 동작에 영향이 없습니다. 단, DOS의 8.3 형식(이름 8자, 확장자 3자 이내, 영문·숫자)을 지켜야 하며 빌드 명령도 바꾼 이름으로 입력합니다.

---

## 3. 실행 예시

입력: A = 17, B = 5

```
Input first number  (0~65535) : 17
Input second number (0~65535) : 5

A + B = 22
A - B = 12
A * B = 85
A / B = 3 ... remainder 2

[Registers after arithmetic]
AX = 0003h  (3)
BX = 0005h  (5)
CX = 0011h  (17)
DX = 0002h  (2)
```

---

## 4. 프로그램 흐름

```
시작
 │
 ├─ 첫 번째 수 입력  → NUM1
 ├─ 두 번째 수 입력  → NUM2
 │
 ├─ CX ← A,  BX ← B
 ├─ 덧셈   (ADD / ADC)
 ├─ 뺄셈   (SUB, 음수면 NEG)
 ├─ 곱셈   (MUL)
 ├─ 나눗셈 (DIV, B = 0이면 건너뜀)
 │
 ├─ ★ AX, BX, CX, DX 값을 메모리에 저장
 │
 ├─ 사칙연산 결과 출력
 ├─ 저장해 둔 레지스터 값 출력
 │
종료 (INT 21h, AH = 4Ch)
```

### 레지스터를 먼저 저장하는 이유
결과를 화면에 출력하는 과정(`INT 21h`, 10진수 변환 등)에서 AX~DX 값이 계속 바뀝니다. 그래서 **연산이 끝난 바로 그 순간**의 값을 `R_AX`, `R_BX`, `R_CX`, `R_DX` 변수에 먼저 보관하고, 모든 결과를 출력한 뒤 이 값을 출력합니다.

### 연산 직후 레지스터 상태
마지막 연산이 나눗셈(`DIV BX`)이므로 다음과 같은 값이 남습니다.

| 레지스터 | 값 | 설명 |
|----------|----|------|
| AX | 몫 | `DIV` 결과 |
| BX | B | 나누는 수 (두 번째 입력값) |
| CX | A | 첫 번째 입력값 |
| DX | 나머지 | `DIV` 결과 |

> B가 0이면 나눗셈을 하지 않으므로 곱셈 직후의 값(AX = 곱의 하위 16비트, DX = 상위 16비트)이 출력됩니다.

---

## 5. 연산별 구현 내용

| 연산 | 사용 명령어 | 특징 |
|------|-------------|------|
| 덧셈 | `ADD`, `ADC` | 16비트를 넘는 자리올림을 DX에 반영해 32비트로 처리 |
| 뺄셈 | `SUB`, `JNC`, `NEG` | 결과가 음수(CF = 1)이면 절댓값을 구하고 `-` 부호 표시 |
| 곱셈 | `MUL` | 결과가 DX:AX(32비트)에 저장됨 |
| 나눗셈 | `DIV` | DX를 0으로 초기화한 뒤 DX:AX ÷ BX → AX = 몫, DX = 나머지 |

---

## 6. 프로시저 및 매크로

| 이름 | 종류 | 기능 |
|------|------|------|
| `PRINT` | 매크로 | `$`로 끝나는 문자열 출력 (`INT 21h`, `AH = 09h`) |
| `READ_NUM` | 프로시저 | 키보드로 10진수를 입력받아 AX에 반환. Enter로 종료, 숫자 외 문자는 무시 |
| `PRINT_U32` | 프로시저 | DX:AX의 32비트 값을 10진수로 출력 (10으로 반복 나눠 스택에 쌓은 뒤 역순 출력) |
| `PRINT_HEX16` | 프로시저 | AX를 16진수 4자리로 출력 (`ROL`로 4비트씩 회전) |
| `PRINT_REG` | 프로시저 | AX를 `XXXXh (10진수)` 형식으로 출력 |

---

## 7. 사용한 DOS 인터럽트

| 기능 | 호출 | 설명 |
|------|------|------|
| 한 글자 입력 | `AH = 01h`, `INT 21h` | 입력한 문자가 AL에 저장되고 화면에 표시됨 |
| 한 글자 출력 | `AH = 02h`, `INT 21h` | DL의 문자 출력 |
| 문자열 출력 | `AH = 09h`, `INT 21h` | DS:DX의 `$` 종료 문자열 출력 |
| 프로그램 종료 | `AH = 4Ch`, `INT 21h` | DOS로 복귀 |

---

## 8. 정리 및 배운 점

- `MUL`과 `DIV`는 피연산자를 하나만 쓰고, **AX와 DX를 암묵적으로 사용**합니다. 16비트 `DIV` 전에는 DX를 반드시 0으로 초기화해야 합니다(안 하면 잘못된 결과가 나오거나 오류가 납니다).
- `SUB` 후 **CF(Carry Flag)** 로 부호 없는 뺄셈의 음수 여부를 판단할 수 있습니다.
- `INT 21h` 같은 출력 루틴은 레지스터 값을 바꾸므로, 특정 시점의 레지스터 값을 보려면 **메모리에 먼저 저장**해야 합니다.
- 숫자를 화면에 출력하려면 2진 값을 10진수·16진수 **문자(ASCII)로 변환**하는 과정이 필요합니다.

---

## 9. 제한 사항

- 입력값은 부호 없는 16비트(0 ~ 65535)만 지원하며, 범위를 넘으면 하위 16비트만 남습니다.
- 입력 중 Backspace로 지우는 기능은 지원하지 않습니다.
- 음수 입력은 지원하지 않습니다.
