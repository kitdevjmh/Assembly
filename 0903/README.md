## 1. 컴퓨터란?
컴퓨터는 입력받은 데이터를 정해진 명령(프로그램)에 따라 처리하여 원하는 결과를 출력하는 전자 장치입니다.

## 2. CPU란?

CPU(Central Processing Unit)는 컴퓨터의 중앙처리장치로, 프로그램의 명령어를 해석하고 연산을 수행하여 컴퓨터의 전반적인 작업을 처리한다.

## 3. Memory란?

Memory는 컴퓨터가 프로그램이나 데이터를 저장하고 필요할 때 꺼내 사용할 수 있도록 하는 저장 공간이다. 일반적으로 CPU가 직접 사용하는 주기억장치(RAM)를 의미한다.

## 4. Debug란?

Debug는 프로그램에서 발생한 오류(Bug)의 원인을 찾아 수정하는 과정이다. 프로그램이 의도한 대로 동작하도록 오류를 분석하고 해결하는 것을 말한다.

## 5. AI 시대에서 왜 Assembly를 배워야 하는지?

Assembly는 컴퓨터가 실제로 명령을 처리하는 과정을 이해할 수 있게 해주는 언어이다. AI가 코드를 작성해 주더라도 Assembly를 알면 CPU, 메모리, 명령어가 실제로 어떻게 동작하는지 이해하고, 프로그램의 오류나 성능 문제를 더 정확하게 분석할 수 있다. 따라서 AI 시대에는 단순히 코드를 작성하는 능력뿐만 아니라 컴퓨터의 동작 원리를 이해하는 능력을 기르기 위해 Assembly를 배울 필요가 있다.
